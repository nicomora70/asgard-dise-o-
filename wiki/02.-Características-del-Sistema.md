# 02. Características del Sistema

## 2.1 Módulos y requisitos

| Módulo | Requisitos |
|---|---|
| Socios y entrenadores | RF01 |
| Catálogo de ejercicios | RF02, RF10 |
| Rutinas | RF03 |
| Entrenamiento (sesiones y series) | RF04, RF05, RF06, RF07 |
| Progresión (motor) | RF08, RF09, RF10, RF11 |
| Reportes | RF12 |

## 2.2 Requisitos funcionales

| ID | Requisito | Implementación |
|---|---|---|
| RF01 | Registrar socios (datos físicos, lesiones, nivel, objetivo y entrenador asignado) y entrenadores | `SocioService`, `EntrenadorService` |
| RF02 | Catálogo de ejercicios con grupo muscular, tipo, equipamiento, incremento de carga y sustitutos | `EjercicioService`, `GrafoEjercicios` |
| RF03 | El entrenador asigna una rutina semanal: día × posición → ejercicio con series, rango de repeticiones y RPE objetivo | `RutinaService`, `PlanSemanal` (matriz 2D) |
| RF04 | Consultar la sesión que toca hoy, dando prioridad a la pendiente más antigua | `SesionService`, `ColaSesiones` (cola FIFO) |
| RF05 | Registrar una serie en un paso (ejercicio, peso y repeticiones; RPE opcional) | `SerieService.registrar` |
| RF06 | Advertir sin bloquear si la carga supera lo sugerido en más de 10 % o si el RPE es 9.5 o más | `SerieService.validar` |
| RF07 | Deshacer la última serie registrada | `PilaDeshacer` (pila LIFO) |
| RF08 | Estimar el 1RM y sugerir la carga y las repeticiones de la siguiente sesión | `CalculadoraCarga`, `MotorProgresion` |
| RF09 | Semáforo de progreso por ejercicio: VERDE progresa, AMARILLO estancado, ROJO retrocede | `CalculadoraCarga.semaforo` |
| RF10 | Ante un estancamiento, sugerir descarga o un ejercicio sustituto que no cargue un grupo lesionado | `GrafoEjercicios` (recorrido en anchura) |
| RF11 | Ordenar los ejercicios del socio según cuánta atención necesitan | `MonticuloMaximo` (Max-Heap) |
| RF12 | Historial de series y sesiones, y reporte PDF de progreso para el entrenador | `HistorialService`, `ReporteService` |

## 2.3 Historias de usuario

Cada historia es un issue del repositorio, con sus criterios de aceptación.

| ID | Historia | Módulo | Prioridad |
|---|---|---|---|
| US001 | Como socio, quiero registrar mis datos, mis lesiones y mi entrenador para que el sistema lleve mi historial | Socios | Alta |
| US002 | Como entrenador, quiero registrarme con mi turno y mi cupo de socios para atenderlos | Socios | Media |
| US003 | Como entrenador, quiero crear ejercicios con sus sustitutos para armar rutinas | Catálogo | Alta |
| US004 | Como entrenador, quiero asignar una rutina semanal al socio para guiar su entrenamiento | Rutinas | Alta |
| US005 | Como socio, quiero ver la sesión que me toca hoy para no desordenar mi rutina si falté un día | Entrenamiento | Alta |
| US006 | Como socio, quiero registrar una serie en un solo paso para no perder tiempo entre series | Entrenamiento | Alta |
| US007 | Como socio, quiero recibir una advertencia si levanto mucho más de lo sugerido, sin que me bloquee | Entrenamiento | Alta |
| US008 | Como socio, quiero deshacer la última serie para corregir un error de registro | Entrenamiento | Media |
| US009 | Como socio, quiero ver la carga sugerida para la siguiente sesión para progresar sin lesionarme | Progresión | Alta |
| US010 | Como socio, quiero ver el semáforo de progreso de cada ejercicio para saber cómo voy | Progresión | Alta |
| US011 | Como socio, quiero recibir una descarga o un sustituto cuando me estanco para seguir progresando | Progresión | Alta |
| US012 | Como entrenador, quiero ver los ejercicios que más atención necesitan para priorizar mi asesoría | Progresión | Media |
| US013 | Como entrenador, quiero registrar una serie asistida por el socio para apoyar su entrenamiento | Entrenamiento | Media |
| US014 | Como entrenador, quiero el historial y un reporte PDF del socio para evaluar su progreso | Reportes | Alta |

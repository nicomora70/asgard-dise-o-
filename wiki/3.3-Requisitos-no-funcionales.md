# 3.3 Requisitos no funcionales

| ID | Atributo | Requisito |
|---|---|---|
| RNF-001 | Usabilidad | Registrar una serie en un solo paso (`ejercicioId`, `peso`, `repeticiones`); advertencias en español |
| RNF-002 | Rendimiento | La progresión se calcula en menos de 200 ms; la respuesta incluye `tiempoCalculoMs` |
| RNF-003 | Confiabilidad | Tipado estricto (enum, record, validación de DTO); fechas en UTC con `Instant`; deshacer no borra el historial |
| RNF-004 | Escalabilidad modular | El motor no depende de la base de datos ni de Spring Web |
| RNF-005 | Usabilidad de la API | Códigos 400, 404 y 409 con mensaje descriptivo en español |
| RNF-006 | Privacidad | El socio controla la exportación y puede eliminar sus datos en cascada |
| RNF-007 | Mantenibilidad | Incrementos, umbrales y porcentajes del motor configurables en `application.properties` |
| RNF-008 | Disponibilidad | Contenedor Docker con chequeo de salud en `/actuator/health` |

# 3.2 Restricciones

**De negocio:**

| ID | Restricción |
|---|---|
| RT-01 | El sistema sugiere pero no impide: registrar más carga de la sugerida solo genera una advertencia |
| RT-02 | Deshacer no borra datos: la serie queda marcada como `deshecha` |
| RT-03 | El reporte PDF lo controla el socio (datos de salud) |
| RT-04 | Desarrollo individual, con entrega en el semestre |
| RT-05 | Solo backend (API REST), sin interfaz gráfica propia |

**De tecnología:**

| ID | Restricción |
|---|---|
| RT-06 | Java 21 (LTS), Spring Boot y Maven Wrapper (`mvnw`) |
| RT-07 | MongoDB por medio de Spring Data MongoDB; Atlas en producción |
| RT-08 | Diagramas UML en Visual Paradigm |
| RT-09 | Pruebas con Postman y documentación con Swagger UI |

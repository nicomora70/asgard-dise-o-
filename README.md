# Asgard - Progresión de cargas en el gimnasio (Backend)

Backend de **Asgard**, un sistema para socios de gimnasio que registra cada serie, estima la fuerza máxima de cada
ejercicio, sugiere la carga de la siguiente sesión, detecta estancamientos y propone una descarga o un ejercicio
sustituto.

El caso de estudio, los requisitos y los diagramas están en la
[wiki del repositorio](https://github.com/nicomora70/asgard-dise-o-/wiki).
